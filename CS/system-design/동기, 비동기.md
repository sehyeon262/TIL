## 동기 / 비동기

### 1. 한 줄 정의
- 동기(Synchronous): 작업이 끝날 때까지 기다렸다가 다음 작업을 진행하는 방식

- 비동기(Asynchronous): 작업이 끝날 때까지 기다리지 않고, 다음 작업을 먼저 진행하는 방식


### 2. 쉽게 이해하기
- 동기 = 줄 서서 한 명 끝나면 다음 사람
- 비동기 = 주문만 해두고, 음식 나올 때까지 다른 일 하는 것

> 즉, **동기**는 순서대로 처리하는 느낌이고, **비동기**는 기다리지 않고 동시에 다른 작업을 할 수 있는 느낌임.


### 3. 예시
#### 동기
- 파일 읽기
- 파일 읽기 끝날 때까지 대기
- 다음 코드 실행

#### 비동기
- 파일 읽기 요청
- 끝날 때까지 안 기다리고 다음 코드 실행
- 파일 읽기 끝나면 나중에 결과 처리


### 4. 장단점
#### 동기
- 장점
    - 흐름이 단순해서 이해하기 쉬움
    - 순서 보장이 쉬움

- 단점
    - 오래 걸리는 작업이 있으면 전체가 멈춘 것처럼 느려짐

#### 비동기
- 장점
    - 자원을 효율적으로 사용할 수 있음
    - 네트워크 요청, 파일 입출력 같은 작업에서 성능상 유리함

- 단점
    - 코드 흐름이 복잡해질 수 있음
    - 실행 순서를 예측하기 어려워 버그가 생길 수 있음


### 5. 면접에서 자주 묻는 것
- 동기와 비동기의 차이는 무엇인가요?
- 비동기를 사용하는 이유는 무엇인가요?
- 자바스크립트에서 비동기는 어떻게 처리하나요?
- Promise, async/await는 왜 필요한가요?


### 6. 같이 헷갈리는 개념
- 동기/비동기는 작업 완료를 기다리느냐의 개념
- 블로킹/논블로킹은 제어권을 넘기고 멈추느냐 아니냐의 개념
