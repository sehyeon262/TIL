## JVM (Java Virtual Machine)

- JVM은 운영체제 위에서 자바 바이트코드를 해석하고 실행하는 역할을 함
- 즉, 자바 코드는 바로 실행되는 게 아니라, Javac 컴파일러가 .java 파일을 .class 파일로 변환하고, 이 바이트코드를 JVM이 실행함.
- 이 덕분에 자바는 "한 번 작성하면, 어디서나 실행된다 (Write Once, Run Anywhere)"는 특징을 가짐

- JVM은 크게 클래스 로더, 실행 엔진, 메모리 영역 세 부분으로 구성됨
    - **클래스 로더**는 바이트코드를 메모리에 올리고,
    - **실행 엔진**은 이를 인터프리팅 또는 JIT (Just-In-Time) 컴파일을 통해 기계어로 변환해 실행함
    - **메모리 영역**은 스택, 힙, 메서드 영역, PC 레지스터, 네이티브 메서드 스택 등으로 나뉘며, 플로그램 실행 중 필요한 데이터를 관리함

- 운영체제마다 다른 환경에서도 JVM이 중간에서 추상화 역할을 하기 때문에, 자바는 높은 이식성을 유지할 수 있음

### 결론
- JVM은 자바 프로그램이 운영체제의 의존하지 않고 실행되도록 해주는 핵심 기반 환경이라고 할 수 있음

### 질문
- 스택과 힙의 차이점을 묻는 꼬리질문이 출제된 적이 있음
