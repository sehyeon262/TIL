## Multi-thread
**멀티스레딩은 하나의 프로세스 안에서 여러 스레드를 생성해 동시에 작업을 처리하는 기법임**

- 스레드는 프로세스 내에서 실행되는 가장 작은 단위로, 메모리와 자원을 공유하면서 실행됨.
- 멀티스레딩을 사용하면 CPU의 활용도를 높이고, 동시에 여러 작업을 병렬적으로 처리할 수 있음..
- 예를 들어, 게임 프로그램에서 화면을 그리는 스레드와 배경 음악을 재생하는 스레드가 동시에 동작할 수 있음
- 징점으로는 응답 속도가 빨라지고, 자원 활용이 효율적임
- 하지만 동기화 문제와 교착상태(deadlock) 같은 위험이 존재해 주의 깊은 설계가 필요함.
- 멀티프로세스와 비교하면 메모리를 공유하기 때문에 문맥 전환 비용이 적지만. 안정성 측면에서는 더 취약할 수 있음
- 자바, 파이썬, C++ 등 대부분의 언어에서 멀티스레딩을 지원하는 라이브러리를 제공함
- 최근에는 멀티코어 CPU가 보편화되면서 멀티스레딩의 중요성이 더욱 커졌음
