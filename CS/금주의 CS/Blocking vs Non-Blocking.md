## Blocking
- Blocking은 작업을 요청한 후 해당 작업이 끝날 때까지 다음 작업을 하지 못하고 기다리는 방식이다.
- 즉, 응답이 올 때까지 프로그램이 멈춰 있는 상태이다.

### 예시
**파일을 읽는 작업**

1. 파일 읽기 요청
2. 파일 읽기 완료될 때까지 대기
3. 이후 다음 코드 실행

=>  요청한 작업이 끝날 때까지 흐름이 멈춤

---

## Non-Blocking
- Non-Blocking은 작업을 요청한 후 응답을 기다리지 않고 바로 다음 작업을 수행하는 방식이다.
- 즉, 결과가 아직 없어도 프로그램이 계속 실행된다.

### 예시
1. 파일 읽기 요청
2. 결과 기다리지 않고 다음 코드 실행
3. 나중에 결과 확인

=> 프로그램이 멈추지 않는다

---

## 차이
| 구분      | Blocking     | Non-Blocking |
| ------- | ------------ | ------------ |
| 실행 흐름   | 작업 끝날 때까지 대기 | 기다리지 않음      |
| 프로그램 상태 | 멈춤           | 계속 실행        |
| 성능      | 상대적으로 느림     | 효율적          |

---

## 실제 예시
웹 서버에서
- **Blocking 서버**
  -> 요청 하나 처리하는 동안 다른 요청 못 처리

- **Non-Blocking 서버**
  -> 여러 요청 동시에 처리 가능

그래서 Node.js, Nginx 같은 서버가 Non-Blocking 방식을 많이 사용한다.
