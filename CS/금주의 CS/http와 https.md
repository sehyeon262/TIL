## http와 https

### HTTP
- 우리가 흔히 아는 웹 통신 프로토콜인데, 데이터가 암호화되지 않고 평문으로 전송됨
- 그래서 누군가 네트워크를 가로채면 요청이나 응답 내용을 그대로 볼 수 있다는 큰 단점이 있음

### HTTPS
- HTTP에 TLS 보안 계층을 더한 것
- 데이터를 주고받을 때 암호화를 적용함
- 그래서 기밀성이 보장되고, 중간에 누가 패킷을 가로채더라도 내용을 해석하기 어려움
- 또한 인증서를 통해 서버의 신원을 확인할 수 있기 때문에 피싱 사이트 같은 위장된 서버와의 연결을 방지할 수 있음
- 무결성 측면에서도 데이터가 전송 중에 변조되면 감지할 수 있어 보안성이 훨씬 높음
- 다만, HTTPS를 쓰려면 인증서 발급과 관리가 필요하고, 예전에는 암호화 과정 때문에 성능 부담이 있었지만, 최근에는 TLS 1.3 같은 기술 덕분에 오버 헤드가 거의 없음

### 결론
- **HTTP**는 빠르고 단순하지만 보안이 없음
- **HTTPS**는 암호화, 인증, 무결성을 제공하는 현대 웹의 표준임
