# Authentication vs Authorization (인증 vs 인가)

## 1. 개념

### 🔐 Authentication (인증)
- **Authentication은 사용자가 "누구인지 확인하는 과정"이다.**
- 즉, 로그인을 통해 사용자의 신원을 검증하는 단계이다.

- 예:
  - 아이디 / 비밀번호 로그인
  - JWT 토큰 검증
  - 지문 / Face ID

---

### 🔑 Authorization (인가)
- **Authorization은 인증된 사용자가 "무엇을 할 수 있는지" 결정하는 과정이다.**
- 즉, 사용자의 권한을 확인하는 단계이다.

- 예:
  - 관리자만 접근 가능
  - 일반 유저는 조회만 가능

---

## 2. 차이 정리

| 구분 | Authentication (인증) | Authorization (인가) |
|---|---|---|
| 의미 | 사용자 확인 | 권한 확인 |
| 시점 | 로그인 시 | 로그인 이후 |
| 질문 | "누구인가?" | "무엇을 할 수 있는가?" |
| 예시 | 로그인 | 관리자 페이지 접근 |

---

## 3. 흐름
1. 사용자 로그인 (Authentication)
2. 인증 성공 → 사용자 식별
3. 요청 시 권한 확인 (Authorization)
4. 허용 / 거부

---

## 4. 실제 예시

### 로그인 과정
- 로그인 성곤 -> 인증 완료

### 이후 요청
- 관리자 페이지 접근 시 -> 권한 확인 후 접근 허용

---

## 5. 핵심 포인트 (면접용)
- 인증 = 신원 확인
- 인가 = 권한 확인
- 인증이 먼저, 인가는 그 다음
- JWT는 인증 + 인가 모두에 사용 가능

---

## 6. 한 줄 정리
> Authentication은 사용자의 신원을 확인하는 것이고, Authorization은 해당 사용자의 권한 확인하는 것이다.
