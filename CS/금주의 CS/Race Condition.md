## Race Condition (레이스 컨디션)
- Race Condition은 여러 스레드나 프로세스가 **공유 자원에 동시에 접근하면서 실행 순서에 따라 결과가 달라지는 상황**을 의미함.
- 즉, 누가 먼저 실행되느냐에 따라 결과가 달라지는 문제이다.

---

### 예시
- 예를 들어 은행 계좌 잔액이 100원이라고 가정하자.
- 두 스레드가 동시에 50원 출금을 실행한다.

1. Thread A
- 잔액 조회 → 100원

2. Thread B
- 잔액 조회 → 100원

3. 둘 다 출금 실행

**결과**
- 정상이라면 → 0원
- Race Condition 발생 → 50원 남을 수도 있음

=> 동시에 접근하면서 데이터가 꼬이는 상황

---

### 왜 발생할까?
Race Condition은 보통 멀티스레드 환경에서 공유 자원 때문에 발생한다.

대표적인 공유 자원
- 변수
- 메모리
- 파일
- 데이터베이스

---

### 해결 방법
1. Mutex (뮤텍스)
- 한 번에 하나의 스레드만 접근 가능

2. Semaphore (세마포어)
- 정해진 여러 개의 스레드만 접근 가능

3. Lock
- 공유 자원 접근 시 잠금

---

### 면접에서 자주 나오는 질문
- Critical Section이 무엇인가
- Mutex vs Semaphore 차이
- Deadlock이란
- 멀티스레드에서 동기화 방법
