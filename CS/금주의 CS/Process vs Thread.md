## Process vs Thread

### Process (프로세스)
**프로세스는 실행 중인 프로그램의 인스턴스이다.**
- 즉, 프로그램을 실행하면 운영체제가 프로세스를 생성하고 메모리 공간을 할당한다.

#### 특징
- 독립적인 메모리 공간을 가짐
- 다른 프로세스와 메모리를 공유하지 않음
- 프로세스 간 통신은 IPC(Inter Process Communication) 필요

#### 예시
- 크롬 브라우저 실행
- 카카오통 실행
- VS Code 실행

=> 각각 별도의 프로세스

---

### Thread (스레드)
**Thread는 프로세스 내부에서 실행되는 작업의 단위이다.**
- 즉, 하나의 프로세스 안에서 여러 작업을 동시에 처리하기 위한 실행 흐름이다.

#### 특징
- 프로세스의 메모리를 공유
- 생성 비용이 프로세스보다 낮음
- 하나의 스레드 오류가 프로세스 전체에 영향을 줄 수 있음

#### 예시
웹 서버
- 요청 처리 스레드 1
- 요청 처리 스레드 2
- 요청 처리 스레드 3

=> 동시에 여러 사용자 요청 처리

---

### 📌 Process vs Thread 차이
| 구분    | Process | Thread |
| ----- | ------- | ------ |
| 메모리   | 독립적     | 공유     |
| 생성 비용 | 큼       | 작음     |
| 안정성   | 높음      | 낮음     |
| 통신    | IPC 필요  | 메모리 공유 |

---

### 면접에서 자주 나오는 추가 질문
- 멀티 프로세스 vs 멀티 스레드 차이
- 스레드에서 동기화 문제 왜 발생하는가
- Race Condition이 무엇인가
- Context Switching이 무엇인가

---

### 한 줄 정리
> Process는 실행 중인 프로그램이고, Thread는 프로세스 내부에서 실행되는 작업의 단위이다.
