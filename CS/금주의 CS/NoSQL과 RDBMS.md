## NoSQL과 RDBMS
- **NoSQL**은 전통적인 관계형 데이터베이스와 달리 정형화되지 않은 데이터를 유연하게 저장하고 처리할 수 있는 비관계형 데이터베이스를 말함

- **RDBMS**는 데이터를 테이블 형태로 저장하고, 각 테이블 간의 관계를 기반으로 SQL 언어를 사용해 데이터를 조작함

### 데이터 저장 방식과 처리 방식 차이
1. RDBMS
- 테이블 형태의 정형 데이터 저장
- 고정된 스키마와 SQL 언어를 사용
- 데이터 간 관계를 명확히 정의
- 트랜잭션과 정합성 유지에 강점 있음

2. NoSQL
- 비정형 또는 반정형 데이터 저장
- 문서, 키-값, 컬럼, 그래프 등 다양한 형태 지원
- 스키마가 유연하고, 수평 확장이 쉬워 대용향 처리에 적합함

### 예)
- 정형 데이터를 안정적으로 관리해야 하는 금융 시스템 => **RDBMS**
- 실시간 로그 분석이나 사용자 피드처럼 빠르고 유연한 처리가 필요한 경우 => **NoSQL**
