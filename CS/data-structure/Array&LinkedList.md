## Array / LinkedList
**Array와 LinkedList는 데이터를 저장하는 방식과 성능 특성이 서로 다른 자료구조**

1. Array
- 데이터가 연속된 메모리 공간에 저장되는 구조
- 인덱스를 통해 특정 위치의 데이터에 바로 접근 가능
- 시간 복잡도 매우 빠름
- 하지만 중간에 데이터 삽입 or 삭제할 경우, 뒤에 있는 모든 데이터를 한 칸씩 이동해야 함.
- 대부분의 Array는 생성 시 크기가 고정되어 확장성이 제한됨

2. LinkedList
- 각 데이터가 노드 형태로 저장되고, 각 노드는 다음 노드를 가리키는 포인터를 가지고 있음
- 메모리에 연속적으로 저장되지 않기 때문에 인덱스 기반 접근이 불가능함
- 특정 위치의 데이터를 찾으려면 순차 탐색이 필요
- 하지만 삽입 or 삭제 시에는 해당 노드의 앞뒤 포인터만 변경하면 되므로, 위치만 알고 있다는 O(1)로 처리 가능
- 크기를 동적으로 조정 -> 유연성 높음

### 결론
- 조회와 인덱스 접근이 중요한 경우 -> **Array**
- 데이터 추가와 삭제가 잦은 경우 -> **LinkedList**


> **질문 유형)** 주로 Array와 LinkedList의 자료구조의 기본구조 차이를 묻는 형식으로 출제되며, Arraylist와 LinkedList를 비교하는 것도 출제된 적 있음
