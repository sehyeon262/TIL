## Cache (캐시)
- 자주 사용하는 데이터를 미리 저장해 두는 고속 저장 공간이다.
- 이를 통해 데이터 접근 속도를 빠르게 만들고 시스템 성능을 향상시킨다.
- 즉, 느린 저장소(DB, 메모리 등)에 접근하기 전에 빠른 저장소에서 먼저 데이터를 찾는 구조이다.

---

### 동작 방식
1. 사용자가 데이터를 요청한다.
2. 캐시에 해당 데이터가 있는지 확인한다.
3. 있다면 -> 캐시에서 바로 반환 (Cache Hit)
4. 없다면 -> DB에서 조회 후 캐시에 저장 (Cache Miss)

---

### 예시
웹 서비스에서 인기 게시글 조회를 생각해보면
- 매번 DB 조회 -> 느림
- 캐시에 저장 -> 빠르게 조회 가능

그래서 보통 **'인기 게시글, 로그인 정보, 자주 조회되는 데이터'** 등을 캐시에 저장한다.

---

### 대표적인 캐시 시스템
- Redis
- Memcached

실무 백엔드에서 거의 필수적으로 사용된다.

---

### 장점
- 데이터 조회 속도 향상
- 서버 부하 감소
- DB 트래픽 감소

---

### 단점
- 캐시와 DB 데이터 불일치 문제
- 캐시 관리 정책 필요 (TTL, LRU 등)

---

### 한 줄 정리
> Cache는 자주 사용하는 데이터를 빠르게 접근하기 위해 임시로 저장하는 고속 저장소이다.
