# Project Deep Dives

프로젝트의 사용자 흐름부터 데이터·이벤트 처리와 AI 기능까지, 직접 담당한 구현을 중심으로 분석합니다.

## Projects

- **DaengDong**: Java/Spring 백엔드와 실시간 통신 중심
- **TravUs**: Vue/Django 풀스택과 외부 API 데이터 통합 중심
- **WISH**: Python 기반 AI 기능 개발과 협업 자동화 중심
- **Icethang**: 프론트엔드 구현과 UX/UI 개선 중심

## 기록 기준

- 전체 요청 및 데이터 흐름
- 팀 기능과 직접 담당한 범위 구분
- 기술을 선택한 이유
- 발생한 문제와 원인
- 해결 및 검증 과정
- 프로젝트 종료 후 개인 개선 사항 구분
- 다시 개발한다면 개선할 점
- 예상 면접 질문과 답변
