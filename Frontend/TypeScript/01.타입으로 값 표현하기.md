- TypeScript에서 가장 먼저 마주하게 되는 개념은 값**을 타입으로 표현하는 방법**
    - 여기서 말하는 값이란, 단순히 문자열이나 숫자 하나 X
    - 변수에 담기는 값, 함수에 전달되는 인자, API 응답으로 돌아오는 데이터까지 코드 안에서 오가는 모든 값이 여기에 해당함.

## 1. Simple Types
- TypeScript의 기본 타입은 코드의 의도를 가장 빠르게 드러내는 도구
- 특히 React 컴포넌트에서는 props와 state의 모양을 명확히 드러내 실수를 줄이는 역할

### ◼️ string

#### 예제
```tsx
const userName: string = "Jisoo";

function greet(name: string) {
    return `Hello, ${name}`;
}
```
- string은 텍스트 데이터를 표현할 때 가장 기본이 되는 타입
- 함수의 입력이 문자열임을 명시하면 숫자나 객체를 실수로 전달하는 상황을 막을 수 있음

#### 실무 예제 (React props로 제목 텍스트 전달)
```tsx
type TitleProps = {
  text: string;
};

function Title({ text }: TitleProps) {
  return <h1>{text}</h1>;
}
```
- UI에서 보여지는 텍스트는 거의 항상 string임

---

### ◼️ number

#### 예제 (가격 계산에서 숫자 사용)
```tsx
const price: number = 12000;
const quantity: number = 2;

const total = price * quantity;
```
- number는 계산이 필요한 값의 기본 타입
- 정수뿐만 아니라 0xf01a (16진수), 0b0001 (2진수), 0o321 (8진수), 3.14 (부동 소수점 숫자)까지 표현할 수 있음
- 사칙연산처럼 숫자 전용 연산을 사용할 수 있고, 문자열과 혼합되는 실수를 막음

#### 실무 예제 (React state로 수량 관리)
```tsx
import { useState } from "react";

function QuantityCounter() {
  const [count, setCount] = useState<number>(1);

  return (
    <button onClick={() => setCount(count + 1)}>
      수량: {count}
    </button>
  );
}
```
