## 🔵 1. React Native의 핵심 컴포넌트 이해하기
- React Native는 웹의 HTML 태그 대신, 모바일 앱을 구성하는 네이티브 컴포넌트들을 사용합니다.
- 러한 컴포넌트들은 각 플랫폼(iOS, Android)의 고유한 UI 요소로 변환되어 화면에 렌더링되므로, 웹뷰를 사용하는 하이브리드 앱보다 훨씬 뛰어난 성능과 사용자 경험을 제공합니다.

### 1. `View`
- View는 UI를 구축하는 가장 기본적인 블록.
- 웹의 `<div>`와 비슷하며, 다른 컴포넌트들을 담는 컨테이너 역할.
- 레이아웃과 스타일을 적용하는 데 주로 사용.
- View는 그 자체로는 눈에 보이지 않지만, 모든 UI 요소의 기반.


### 2. `Text`
- Text는 화면에 텍스트를 표시하는 컴포넌트임 
- **Text 컴포넌트 안에서만 텍스트를 렌더링 가능** 
- React Native는 네이티브 텍스트 렌더링 방식을 사용하기 때문에 웹처럼 View 안에 직접 텍스트를 넣을 수 없음 
- 여러 Text 컴포넌트를 중첩하여 다양한 스타일을 적용할 수도 있음


### 3. `Image`
- Image는 웹의 `<img>` 태그와 같이 이미지를 표시하는 컴포넌트 
- 로컬에 저장된 이미지 파일뿐만 아니라, 네트워크에 있는 이미지를 URI(Uniform Resource Identifier)를 통해 불러올 수도 있음 
- 성능 최적화를 위해 이미지를 캐싱하는 기능도 내장되어 있음


### 4. `Button`
- Button은 사용자가 터치하여 액션을 수행할 수 있는 컴포넌트 
- `title` 속성으로 버튼에 표시될 텍스트를, `onPress` 속성으로 클릭 이벤트를 처리할 함수를 지정함 
- Button은 스타일링 옵션이 제한적이므로, 더 복잡한 디자인의 버튼이 필요할 때는 `TouchableOpacity`나 `Pressable`을 사용해 커스텀 버튼을 만듦.



### 5. `TextInput`
` TextInput은 사용자로부터 텍스트를 입력받을 때 사용함 
- 로그인 폼, 검색창, 댓글 입력창 등에 활용 
- `onChangeText` 속성을 통해 입력된 텍스트의 변화를 감지하고, `value` 속성으로 입력 상태 제어 
- `placeholder`, `keyboardType`, `secureTextEntry` 등 다양한 속성 지원



### 6. `ScrollView와 FlatList`
- 화면에 표시되는 내용이 많아 스크롤이 필요할 때는 `ScrollView`나 `FlatList`를 사용합니다.

    - `ScrollView`
        - 모든 자식 컴포넌트를 한 번에 렌더링 
        - 항목 수가 적을 때 사용하기 좋음

    - `FlatList`
        - 목록의 아이템들을 지연 렌더링(Lazy Rendering)하는 컴포넌트
        - 화면에 보이는 부분만 렌더링하여 성능을 최적화하므로, **항목 수가 많을 때 `FlatList`를 사용하는 것이 좋음**

## 🔵 2. Flexbox를 활용한 레이아웃 설계
- `flexDirection` 
    - 자식 컴포넌트들을 어떤 방향으로 배치할지 결정 (`row`, `column`, `row-reverse`, `column-reverse`) 
    - 기본값은 `column`임

- `justifyContent`
    - 메인 축(Main Axis)을 따라 자식 컴포넌트들을 어떻게 정렬할지 결정
    - `flex-start`, `flex-end`, `center`, `space-between`, `space-around`, `space-evenly`

- `alignItems`
    - 교차 축(Cross Axis)을 따라 자식 컴포넌트들을 어떻게 정렬할지 결정
    - `flex-start`, `flex-end`, `center`, `stretch`, `baseline`

- `flex`
    - 부모 컴포넌트 내에서 자식 컴포넌트가 차지할 공간의 비율을 결정

```js
// Flexbox 예시
import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

const FlexboxExample = () => {
  return (
    <View style={styles.container}>
      <View style={[styles.box, { flex: 1, backgroundColor: 'red' }]} />
      <View style={[styles.box, { flex: 2, backgroundColor: 'green' }]} />
      <View style={[styles.box, { flex: 1, backgroundColor: 'blue' }]} />
    </View>
  );
};

const styles = StyleSheet.create({
  container: {
    flex: 1,
    flexDirection: 'row',
    alignItems: 'center',
    justifyContent: 'center',
  },
  box: {
    height: 100,
    width: 100,
    margin: 5,
  },
});

export default FlexboxExample;
```

- 위 예시에서는 가로(flexDirection: 'row') 방향으로 세 개의 박스를 배치하고, flex 속성을 통해 두 번째 박스가 다른 박스의 두 배 크기를 갖도록 설정함.

## 🔵 네비게이션 기능 추가: `React Navigation`
- 단일 화면(Single-Screen) 앱은 한계가 있음.
- 여러 화면을 유기적으로 연결하고 이동하는 네비게이션(Navigation)은 모바일 앱의 필수 기능임. 
- `React Navigation`은 React Native 앱에서 화면 전환을 관리하는 가장 표준적인 라이브러리.


### 3.1 라이브러리 설치
- `React Navigation`은 여러 패키지로 구성 
- 가장 기본이 되는 패키지들을 설치함
```
# 네비게이션 기본 패키지
npm install @react-navigation/native

# 네이티브 의존성 설치
npm install react-native-screens react-native-safe-area-context
# ios의 경우 pod install
cd ios && pod install
```


### 3.2 Stack Navigator 구현
- 가장 흔한 네비게이션 방식은 **스택 네비게이터(Stack Navigator)**  
- 새로운 화면이 현재 화면 위로 쌓이고(push), 뒤로 가기 버튼을 누르면 화면이 사라지는(pop) 구조임

1. 스택 네비게이터 라이브러리 설치
```
npm install @react-navigation/stack
```

2. 화면 컴포넌트 만들기
- `src/screens` 폴더를 만들고, 두 개의 화면 컴포넌트를 작성

```js
// src/screens/HomeScreen.js
import React from 'react';
import { View, Text, Button } from 'react-native';

const HomeScreen = ({ navigation }) => {
  return (
    <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
      <Text>홈 화면입니다!</Text>
      <Button
        title="상세 페이지로 이동"
        onPress={() => navigation.navigate('Details')}
      />
    </View>
  );
};
export default HomeScreen;
```

```js
// src/screens/DetailsScreen.js
import React from 'react';
import { View, Text, Button } from 'react-native';

const DetailsScreen = ({ navigation }) => {
  return (
    <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
      <Text>상세 페이지입니다!</Text>
      <Button title="뒤로 가기" onPress={() => navigation.goBack()} />
    </View>
  );
};
export default DetailsScreen;
```


3. 네비게이터 설정
- `App.js`에 `NavigationContainer`와 `createStackNavigator`를 사용하여 라우팅을 설정

```js
// App.js
import * as React from 'react';
import { NavigationContainer } from '@react-navigation/native';
import { createStackNavigator } from '@react-navigation/stack';
import HomeScreen from './src/screens/HomeScreen';
import DetailsScreen from './src/screens/DetailsScreen';

const Stack = createStackNavigator();

function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator initialRouteName="Home">
        <Stack.Screen name="Home" component={HomeScreen} options={{ title: '홈' }} />
        <Stack.Screen name="Details" component={DetailsScreen} options={{ title: '상세' }} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}
export default App;
```

- `NavigationContainer` : 모든 네비게이션의 최상위 컨테이너 역할
- `createStackNavigator()` : 스택 네비게이터를 생성
- `<Stack.Screen>` : 네비게이터에 등록할 각 화면을 정의하고, name은 화면의 고유 이름, component는 연결할 컴포넌트
