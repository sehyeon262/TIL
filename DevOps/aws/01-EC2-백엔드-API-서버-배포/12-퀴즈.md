# 📝EC2 백엔드 API 서버 배포 퀴즈

EC2 서버 배포 과정에서 학습한 핵심 내용을 스스로 점검한다.

## 1. 배포란 무엇일까?

개발한 프로그램을 사용자가 실제로 사용할 수 있는 환경에 올리는 작업을 무엇이라고 할까?

<details>
<summary>정답 보기</summary>

배포(Deployment)다.

</details>

## 2. EC2란 무엇일까?

EC2는 AWS에서 제공하는 가상 서버 서비스다.

EC2를 한 문장으로 설명해 보자.

<details>
<summary>정답 보기</summary>

AWS에서 필요한 만큼 생성하고 사용할 수 있는 가상 컴퓨터다.

</details>

## 3. 리전을 선택하는 기준은 무엇일까?

한국 사용자를 대상으로 하는 서비스라면 주로 어떤 리전을 선택할까?

<details>
<summary>정답 보기</summary>

사용자와 가까운 `아시아 태평양(서울)` 리전을 선택한다. 리전 코드는 `ap-northeast-2`다.

</details>

## 4. 보안 그룹의 역할은 무엇일까?

보안 그룹은 EC2 주변의 무엇과 비슷한 역할을 할까?

<details>
<summary>정답 보기</summary>

서버로 들어오고 나가는 네트워크 요청을 제어하는 방화벽 역할이다.

</details>

## 5. IP와 Port의 차이는 무엇일까?

IP와 Port는 각각 무엇을 가리킬까?

<details>
<summary>정답 보기</summary>

IP는 네트워크에서 특정 컴퓨터를 가리키는 주소다.

Port는 그 컴퓨터에서 실행 중인 특정 프로그램을 가리키는 번호다.

</details>

## 6. SSH 접속에 사용하는 Port는 무엇일까?

EC2에 원격으로 접속할 때 사용하는 기본 Port 번호는 무엇일까?

<details>
<summary>정답 보기</summary>

`22`번 Port다.

</details>

## 7. 탄력적 IP가 필요한 이유는 무엇일까?

EC2를 중지했다가 다시 시작해도 같은 IP 주소를 사용하려면 무엇을 연결해야 할까?

<details>
<summary>정답 보기</summary>

탄력적 IP(Elastic IP)를 연결한다.

</details>

## 8. `.env`와 `application.yml`을 GitHub에 올리면 안 되는 이유는 무엇일까?

<details>
<summary>정답 보기</summary>

데이터베이스 비밀번호, API 키처럼 민감한 정보가 포함될 수 있기 때문이다.

</details>

## 9. Express 서버 실행에 사용하는 프로세스 관리 도구는 무엇일까?

<details>
<summary>정답 보기</summary>

PM2다.

</details>

## 10. 실습을 마친 뒤 반드시 정리해야 하는 리소스는 무엇일까?

<details>
<summary>정답 보기</summary>

EC2 인스턴스를 종료하고, 사용하지 않는 탄력적 IP도 릴리스한다.

</details>
