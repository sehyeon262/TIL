# 🧹EC2 실습 후 리소스 정리하기

EC2 실습이 끝났다면 인스턴스와 탄력적 IP를 정리해 불필요한 비용이 발생하지 않도록 한다.

## 정리할 리소스

이번 실습에서 확인할 리소스는 다음과 같다.

- EC2 인스턴스
- 탄력적 IP
- 연결된 EBS 볼륨

## 1. EC2 인스턴스 종료하기

인스턴스를 단순히 중지하는 것과 종료하는 것은 다르다.

| 작업 | 결과 |
| --- | --- |
| 중지 | 인스턴스를 일시적으로 끈다. |
| 종료 | 인스턴스를 삭제한다. |

실습을 완전히 마쳤다면 인스턴스를 종료한다.

1. EC2 콘솔의 `인스턴스` 메뉴로 이동한다.
2. 종료할 인스턴스를 선택한다.
3. `인스턴스 상태` 메뉴를 선택한다.
4. `인스턴스 종료`를 선택한다.
5. 안내 내용을 확인한 뒤 종료한다.

인스턴스 종료는 취소할 수 없으므로, 필요한 파일과 설정이 있다면 먼저 백업한다.

## 2. 탄력적 IP 릴리스하기

탄력적 IP는 사용하지 않는 상태로 남아 있으면 비용이 발생할 수 있다.

인스턴스를 종료한 뒤 탄력적 IP도 릴리스한다.

1. EC2 콘솔의 `탄력적 IP` 메뉴로 이동한다.
2. 실습에서 만든 탄력적 IP를 선택한다.
3. `작업` 메뉴를 선택한다.
4. `탄력적 IP 주소 릴리스`를 선택한다.
5. 안내 내용을 확인한 뒤 릴리스한다.

릴리스한 탄력적 IP 주소는 더 이상 내 AWS 계정에서 사용할 수 없다.

## 3. EBS 볼륨 확인하기

인스턴스를 종료한 뒤에도 EBS 볼륨이 남아 있을 수 있다.

EC2 콘솔의 `볼륨` 메뉴에서 실습용 볼륨이 남아 있는지 확인한다.

삭제해도 되는 실습용 볼륨이라면, 연결된 인스턴스가 없는지 확인한 뒤 삭제한다.

## 최종 확인 목록

- [ ] EC2 인스턴스를 종료했다.
- [ ] 사용하지 않는 탄력적 IP를 릴리스했다.
- [ ] 불필요한 EBS 볼륨이 남아 있지 않은지 확인했다.
- [ ] AWS 결제 및 비용 관리 페이지에서 예상 비용을 확인했다.
