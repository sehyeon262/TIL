# 🔌IP와 Port의 개념

IP와 Port는 인터넷에서 원하는 서버 프로그램에 정확히 요청을 보내기 위해 함께 사용하는 주소 정보다.

## 이 글에서 배우는 것

- IP 주소가 무엇인지 이해하기
- Port 번호가 무엇인지 이해하기
- IP와 Port를 함께 사용하는 이유 알아보기
- 브라우저에서 Port 번호를 생략할 수 있는 이유 이해하기
- 자주 사용하는 Port 번호 알아보기

## 먼저 알아야 할 핵심 개념

### 1) IP란?

IP는 네트워크 안에서 특정 컴퓨터를 가리키는 주소다.

예를 들어 아래와 같은 값이 IP 주소다.

```text
13.250.15.132
```

사용자가 서버에 요청을 보내려면, 먼저 어떤 컴퓨터에 요청을 보낼지 알아야 한다. 이때 사용하는 정보가 IP 주소다.

도메인 주소인 `naver.com`도 결국 DNS를 통해 실제 서버의 IP 주소로 변환된다.

### 2) Port란?

Port는 한 컴퓨터 안에서 실행 중인 특정 프로그램을 가리키는 번호다.

서버 컴퓨터 한 대에서는 여러 프로그램이 동시에 실행될 수 있다. 따라서 IP 주소만으로는 어떤 프로그램과 통신해야 하는지 알 수 없다.

예를 들어 아래 주소에서 `3000`이 Port 번호다.

```text
13.250.15.132:3000
```

- `13.250.15.132`: 요청을 보낼 컴퓨터의 주소
- `3000`: 그 컴퓨터 안에서 실행 중인 특정 프로그램의 주소

## IP와 Port를 함께 사용하는 이유

EC2 한 대에서 Express 서버, Spring Boot 서버, 데이터베이스 등 여러 프로그램을 실행할 수 있다.

사용자는 IP 주소로 컴퓨터를 찾고, Port 번호로 그 안의 특정 서버 프로그램을 찾는다.

```mermaid
flowchart LR
    User["사용자"] -->|"13.250.15.132:3000 요청"| EC2["EC2 컴퓨터"]
    EC2 -->|"3000번 Port"| API["백엔드 API 서버"]
```

즉, IP는 **어느 컴퓨터인지**, Port는 **그 컴퓨터 안의 어느 프로그램인지**를 나타낸다.

## 브라우저 주소에 Port 번호를 쓰지 않는 이유

브라우저에서 아래처럼 도메인만 입력해도 웹 페이지에 접속할 수 있다.

```text
http://example.com
```

HTTP 통신은 기본적으로 `80`번 Port를 사용한다. 그래서 주소에 Port 번호를 생략하면 브라우저는 기본 Port인 `80`번으로 요청을 보낸다.

반대로 서버가 `3000`번 Port에서 실행 중이라면 Port 번호를 직접 입력해야 한다.

```text
http://example.com:3000
```

HTTPS는 기본적으로 `443`번 Port를 사용한다.

```text
https://example.com
```

## 잘 알려진 Port

Port 번호는 `0`부터 `65,535`까지 사용할 수 있다.

이 중 `0`부터 `1,023`까지는 주요 통신 규약에서 용도를 정해 둔 잘 알려진 Port(Well-known Port)다.

| Port | 사용 목적 | AWS 학습에서 사용하는 상황 |
| --- | --- | --- |
| `22` | SSH 원격 접속 | 내 컴퓨터에서 EC2에 접속할 때 |
| `80` | HTTP 통신 | 웹 서버에 HTTP 요청을 보낼 때 |
| `443` | HTTPS 통신 | HTTPS가 적용된 웹 서버에 접속할 때 |

정해진 Port 번호를 반드시 사용해야 하는 것은 아니다. 예를 들어 HTTP 서버를 `3000`번이나 `8080`번 Port에서 실행할 수도 있다.

다만 사용자가 접속할 때 기본 Port가 아닌 번호를 사용한다면, 주소에 Port 번호를 함께 작성해야 한다.

## 보안 그룹과 Port

EC2 보안 그룹에서는 외부에서 접근할 수 있는 Port를 설정한다.

예를 들어 Express 서버가 `3000`번 Port에서 실행 중이라면, 외부에서 직접 접속하려면 보안 그룹 인바운드 규칙에도 `3000`번 Port를 열어야 한다.

필요하지 않은 Port를 외부에 열어 두면 보안 위험이 커질 수 있으므로, 필요한 Port만 허용한다.
