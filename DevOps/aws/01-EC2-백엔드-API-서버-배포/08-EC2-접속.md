# 🔐EC2에 접속하기

생성한 EC2 인스턴스의 상태와 IP 주소를 확인하고, AWS 콘솔에서 서버에 접속하는 방법을 정리한다.

## 이 글에서 배우는 것

- EC2 인스턴스 정보 확인하기
- 퍼블릭 IPv4 주소의 역할 이해하기
- EC2 Instance Connect로 접속하기
- 인스턴스 중지, 재부팅, 종료의 차이 알아보기

## 인스턴스 정보 확인하기

AWS EC2 콘솔에서 생성한 인스턴스를 선택하면 여러 정보를 확인할 수 있다.

처음에는 아래 두 정보를 가장 중요하게 확인하면 된다.

| 항목 | 의미 |
| --- | --- |
| 인스턴스 상태 | EC2 컴퓨터가 실행 중인지 나타내는 상태 |
| 퍼블릭 IPv4 주소 | 외부에서 EC2에 접속할 때 사용하는 IP 주소 |

인스턴스 상태가 `실행 중(Running)`이면 EC2 컴퓨터가 켜져 있는 상태다.

퍼블릭 IPv4 주소는 외부에서 EC2 서버에 접근할 때 사용한다.

```text
http://<퍼블릭-IPv4-주소>
```

## 인스턴스의 다른 정보

인스턴스 상세 화면에서는 다음 정보도 확인할 수 있다.

| 메뉴 | 확인할 수 있는 내용 |
| --- | --- |
| 보안 | 연결된 보안 그룹과 인바운드 규칙 |
| 네트워킹 | 퍼블릭 IPv4 주소, VPC, 서브넷 |
| 스토리지 | 연결된 EBS 볼륨 |
| 모니터링 | CPU 사용률 등 인스턴스 성능 지표 |

실제 서버를 운영할 때는 모니터링 지표를 통해 서버가 정상적으로 동작하는지 확인한다.

## EC2에 접속하기

AWS 콘솔에서 EC2에 접속하는 방법은 다음과 같다.

1. EC2 콘솔에서 접속할 인스턴스를 선택한다.
2. 상단의 `연결(Connect)` 버튼을 누른다.
3. `EC2 Instance Connect` 탭을 선택한다.
4. `연결(Connect)` 버튼을 누른다.

연결에 성공하면 브라우저에서 Ubuntu 터미널을 사용할 수 있다.

```text
ubuntu@ip-<내부-IP>:~$
```

이 터미널에서 Node.js, Java, Git 등의 프로그램을 설치하고 서버를 실행할 수 있다.

## 인스턴스 상태 변경

EC2 인스턴스는 일반 컴퓨터처럼 재부팅하거나 끌 수 있다.

| 작업 | 의미 |
| --- | --- |
| 재부팅 | 컴퓨터를 다시 시작한다. |
| 중지 | 컴퓨터를 일시적으로 끈다. |
| 시작 | 중지된 인스턴스를 다시 켠다. |
| 종료 | 인스턴스를 삭제한다. |

인스턴스를 중지한 뒤 다시 시작하면 기본 퍼블릭 IPv4 주소가 변경될 수 있다.

인스턴스 종료는 취소할 수 없으므로, 필요한 파일과 설정을 확인한 뒤 실행한다.
