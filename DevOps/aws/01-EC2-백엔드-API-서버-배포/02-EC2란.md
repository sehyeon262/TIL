# 📖EC2란?

EC2(Elastic Compute Cloud)는 AWS에서 빌려 사용하는 가상 컴퓨터다.

백엔드 서버를 실행하고, 인터넷을 통해 다른 사용자가 API에 접근할 수 있도록 만드는 데 사용한다.

## EC2를 쉽게 이해하기

EC2는 원격으로 접속해 사용하는 컴퓨터라고 생각하면 된다.

내 컴퓨터처럼 운영체제를 설치하고, 프로그램을 실행하고, 파일을 저장할 수 있다. 차이점은 내 책상 위에 있는 컴퓨터가 아니라 AWS 데이터 센터에 있는 컴퓨터를 빌려 사용한다는 점이다.

## EC2를 왜 사용할까?

### 1) 내 컴퓨터를 계속 켜 둘 필요가 없다

내 컴퓨터에서 서버를 운영하면 사용자가 접속하는 동안 컴퓨터를 계속 켜 두어야 한다.

EC2를 사용하면 AWS 환경에서 서버를 실행하므로, 내 컴퓨터가 꺼져 있어도 서비스는 계속 실행할 수 있다.

### 2) 외부 사용자가 서버에 접근할 수 있다

EC2에는 외부에서 접근할 수 있는 공인 IP 주소를 연결할 수 있다.

사용자는 이 IP 주소나 연결된 도메인 주소를 통해 백엔드 API 서버에 요청을 보낼 수 있다.

### 3) AWS 서비스와 함께 사용할 수 있다

EC2는 다른 AWS 서비스와 연결해 사용할 수 있다.

- ELB: 사용자 요청을 서버에 분산하고 HTTPS를 적용한다.
- RDS: 데이터베이스를 별도 환경에서 운영한다.
- S3: 이미지와 파일을 저장한다.
- CloudWatch: 서버 로그와 상태를 확인한다.
- Auto Scaling: 트래픽에 따라 서버 수를 자동으로 조절한다.

## 현업에서는 EC2를 언제 사용할까?

EC2는 주로 백엔드 API 서버를 배포할 때 사용한다.

Express, Spring Boot, Django처럼 서버에서 실행되는 애플리케이션을 EC2에 배포할 수 있다.

또한 개발 서버, 테스트 서버, 배치 작업, 자동화 프로그램을 실행하는 용도로도 사용할 수 있다.

## 프론트엔드도 EC2에 배포할까?

프론트엔드 웹 페이지도 EC2에 배포할 수 있다.

하지만 HTML, CSS, JavaScript로 구성된 정적 웹 페이지는 EC2보다 S3, CloudFront, Vercel, Netlify 같은 서비스를 사용하는 경우가 많다.

이 학습에서는 EC2를 백엔드 API 서버를 배포하는 서비스로 이해하면 된다.

## 정리

- EC2는 AWS에서 제공하는 가상 컴퓨터다.
- 백엔드 API 서버를 인터넷에 배포할 때 주로 사용한다.
- 내 컴퓨터를 계속 켜 두지 않고 서버를 운영할 수 있다.
- ELB, RDS, S3 같은 AWS 서비스와 함께 사용할 수 있다.
