# 🕰️RDS 파라미터 그룹 설정: 이전 AWS UI

> 이 문서는 이전 AWS 콘솔 화면을 사용하던 시기의 참고용 기록이다.  
> 실제 실습은 [RDS 파라미터 그룹 설정하기](../05-파라미터-그룹.md)를 따른다.

이전 UI에서도 사용자 지정 파라미터 그룹을 생성한 뒤 RDS 인스턴스에 연결하는 흐름은 동일하다.

## 핵심 설정값

| 파라미터 | 값 |
| --- | --- |
| `character_set_client` | `utf8mb4` |
| `character_set_connection` | `utf8mb4` |
| `character_set_database` | `utf8mb4` |
| `character_set_filesystem` | `utf8mb4` |
| `character_set_results` | `utf8mb4` |
| `character_set_server` | `utf8mb4` |
| `collation_connection` | `utf8mb4_unicode_ci` |
| `collation_server` | `utf8mb4_unicode_ci` |
| `time_zone` | `Asia/Seoul` |

## 적용 순서

1. 현재 RDS MySQL 엔진 버전에 맞는 파라미터 그룹 패밀리를 선택한다.
2. 사용자 지정 파라미터 그룹을 생성한다.
3. 문자 인코딩과 시간대를 수정한다.
4. RDS 인스턴스 수정 화면에서 생성한 그룹을 연결한다.
5. 재부팅이 필요한 설정은 RDS를 재부팅한다.

## 주의 사항

파라미터 그룹을 만들거나 수정한 것만으로는 RDS에 적용되지 않는다.

반드시 DB 인스턴스에 연결하고, 재부팅이 필요한 항목은 재부팅까지 완료해야 한다.
