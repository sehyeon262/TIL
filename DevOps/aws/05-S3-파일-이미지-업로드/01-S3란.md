# 🪣S3란?

S3(Simple Storage Service)는 AWS에서 파일을 저장하고 조회할 수 있는 객체 스토리지 서비스다.

이미지, 동영상, 문서, 백업 파일처럼 애플리케이션 코드와 분리해서 보관할 파일을 저장할 때 사용한다.

## S3를 사용하는 이유

EC2 서버 내부에 이미지를 저장할 수도 있다. 하지만 서버를 교체하거나 인스턴스가 삭제되면 파일을 잃을 수 있고, 파일이 많아질수록 서버 관리가 복잡해진다.

S3에 파일을 저장하면 애플리케이션 서버와 파일 저장소를 분리할 수 있다.

| EC2 서버에 파일 저장 | S3에 파일 저장 |
| --- | --- |
| 서버 디스크 공간을 사용 | 파일 저장 전용 서비스 사용 |
| 서버 교체 시 파일 관리 필요 | 서버와 파일을 분리해 관리 |
| 여러 서버에서 파일 공유가 어려움 | 여러 서버가 같은 파일에 접근 가능 |
| 파일 전송에 서버 자원 사용 | 파일 저장·조회에 최적화됨 |

## S3의 핵심 용어

| 용어 | 의미 |
| --- | --- |
| 버킷(Bucket) | 파일을 저장하는 최상위 공간 |
| 객체(Object) | 버킷에 저장된 실제 파일 |
| 객체 키(Object Key) | 버킷 안에서 객체를 구분하는 경로와 이름 |
| 객체 URL | 객체에 접근할 수 있는 주소 |
| 버킷 정책(Bucket Policy) | 버킷 또는 객체에 대한 접근 권한 규칙 |

예를 들어 아래 구조에서 `images/profile.png`가 객체 키다.

```text
my-service-bucket/
└─ images/
   └─ profile.png
```

## S3 사용 예시

- 프로필 이미지, 게시글 이미지
- PDF, 엑셀 등 첨부 파일
- 동영상, 음원
- 서비스 로그와 백업 파일
- 정적 웹 사이트 파일
