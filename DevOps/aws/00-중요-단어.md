# 중요 단어

AWS 학습 중 반복해서 등장하는 핵심 용어를 정리한다.

## 💬 ELB

> **한 줄 요약:** 여러 서버에 트래픽을 나누어 주는 로드 밸런서

ELB(Elastic Load Balancer)는 사용자 요청을 여러 서버에 적절히 분배하는 AWS 서비스다.

사람들이 한 계산대에 몰리지 않도록 여러 계산대로 안내하는 직원에 비유할 수 있다.

- 트래픽을 여러 EC2 인스턴스에 분산할 수 있다.
- SSL/TLS 인증서를 적용해 HTTPS 연결을 처리할 수 있다.
- 헬스 체크를 통해 정상적으로 동작하는 서버에만 요청을 전달한다.

## 💬 SSL/TLS

> **한 줄 요약:** 인터넷 통신 내용을 암호화해 HTTPS를 가능하게 하는 보안 기술

SSL/TLS는 클라이언트와 서버 사이의 통신을 암호화하는 프로토콜이다.

HTTPS는 HTTP에 TLS를 적용한 방식이다. 이를 통해 로그인 정보, 개인정보 등 민감한 데이터가 전송 중에 노출되는 위험을 줄일 수 있다.

## 💬 ELB 헬스 체크

> **한 줄 요약:** ELB가 백엔드 서버의 정상 동작 여부를 주기적으로 확인하는 기능

ELB는 설정한 경로(URL) 또는 포트로 EC2 인스턴스에 주기적으로 요청을 보낸다.

- 정상 응답(예: HTTP `200`)을 받으면 `Healthy` 상태가 된다.
- 응답이 없거나 오류가 발생하면 `Unhealthy` 상태가 된다.
- `Unhealthy` 상태의 인스턴스에는 트래픽을 보내지 않는다.

## 💬 ELB 보안 그룹

> **한 줄 요약:** 외부 사용자가 ELB에 들어오는 요청을 제어하는 방화벽

ELB 보안 그룹은 외부에서 ELB로 들어오는 트래픽을 허용하거나 차단한다.

예를 들어 다음과 같이 설정할 수 있다.

- HTTP 포트 `80` 허용
- HTTPS 포트 `443` 허용
- 특정 IP 주소에서만 접근 허용

즉, ELB 보안 그룹은 서비스 앞단에서 동작하는 방화벽 역할을 한다.

## 💬 RDS

> **한 줄 요약:** AWS가 운영 관리를 도와주는 관계형 데이터베이스 서비스

RDS(Relational Database Service)는 관계형 데이터베이스를 쉽게 생성하고 운영할 수 있도록 제공하는 AWS 서비스다.

데이터베이스 설치, 백업, 장애 대응, 업데이트 같은 관리 작업을 AWS가 일부 지원해 준다.
