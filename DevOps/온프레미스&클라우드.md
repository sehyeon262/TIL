## 온프레미스 / 클라우드
**온프레미스와 클라우드는 IT 인프라를 어디에 두고 어떻게 운영하느냐의 차이라고 볼 수 있음**

1. 온프레미스
- 기업이 서버, 네트워크, 스토리지 같은 인프라를 직접 구매해서 사내 전산실에 구축하고 운영하는 방식
- 초기 구축 비용 크고, 하드웨어 관리나 장애 대응을 모두 내부 인력이 책임져야 함
- 다만 데이터가 내부에 존재하기 때문에 **보안이나 통제 측면에서 유리하다**는 장점 존재

2. 클라우드
- 외부 클라우드 서비스 제공업체의 인프라를 인터넷을 통해 사용하는 방식
- 필요한 만큼 자원을 즉시 확장하거나 축소할 수 있어 유연성 높음
- 초기 투자 비용이 적고, 사용한 만큼 비용을 지불하는 구조라 비용 효율성이 좋음
- 서버 관리, 백업, 장애 대응 등을 서비스 재공업체가 담당해 운영 부담이 줄어듦.
- 다만 클라우드는 **외부 환경에 의존하기 때문에 보안 정책이나 규제 준수가 중요한 경우에는 제한이 있을 수 있음**

### 결론
- 두 방식의 선택은 기업의 보안 요구사항, 비용 구조, 서비스 확장석 등을 종합적으로 고려해 결정된다고 생각함

### 질문유형
- 단독으로도 묻지만, 주로 두 가지를 비교하는 질문으로 출제됨
