## JPA (Java Persistence API)

- 자바에서 객체와 관계형 데이터베이스를 매핑하는 ORM 표준 사양임.

#### 장점
- SQL을 직접 작성하지 않고, 엔티티 클래스와 매핑 설정만으로 데이터의 저장, 조회, 수정을 수행할 수 있음
- CRUD 같은 반복적인 SQL 작성 없이 메서드 호출로 처리할 수 있고, 유지보수성 높음
- 테이블 구조 변경 시 SQL 대신 엔티티 클래스만 수정하면 됨
- 표준 API를 사용하므로 데이터베이스 교체 시 코드 수정이 최소화되며, 객체 지향적 데이터 접근이 가능함
- 컬렉션 다루듯이 데이터 조작이 가능

#### 단점
- 러닝 커브 있음
- ORM의 동작 원리와 객체-관계 패러다임 불일치를 이해해야 함
- 복잡한 쿼리는 여전히 JPQL 또는 네이티브 SQL을 작성해야 함
- 잘못 사용하면 성능 저하가 발생할 수 있음

#### 결론
- JPA는 객체 중심 설계와 생산성을 높여주지만, 원리와 제약을 이해하고 사용하는 것이 중요함.
