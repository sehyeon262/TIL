## 웹소켓
- 웹 환경에서 클라이언트와 서버가 실시간으로 양방향 통신을 할 수 있도록 해주는 프로토콜임.

### 1. 기존 웹 통식 방식 (HTTP)
- 클라이언트가 요청(Request) 해야 서버가 응답(Response) 하는 구조
- 요청이 끝나면 연결이 종료됨
- 실시간 데이터가 필요하면 계속 요청을 보내야 해서 비효율적

### 2. 웹소켓(WebSocket) 방식
- 처음에는 HTTP로 연결(핸드셰이크)
- 이후 WebSocket 프로토콜로 전환
- 연결이 유지된 상태에서 클라이언트 ↔ 서버 양방향 통신 가능

### 3. 특징
- 연결을 계속 유지
- 서버와 클라이언트가 필요할 때 바로 데이터 전송
- 지연이 적고 네트워크 효율이 좋음

### 4. 사용되는 서비스
- 채팅 서비스
- 실시간 알림
- 온라인 게임
- 주식 시세
- 스포츠 경기 실시간 데이터
