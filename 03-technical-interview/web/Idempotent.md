## Idempotent (멱등성)
- **같은 요청을 여러 번 수행해도 결과가 항상 동일하게 유지되는 성질**
- 주로 HTTP API 설계, RESTful API, 서버 안정성과 관련된 개념임.


### 멱등성이 왜 중요한가?
네트워크 환경에서는 다음 상왕이 자주 발생함.
- 요청이 실패했는지 알 수 없음
- 응답이 오지 않아 **재요청(retry)** 발생
- 동일한 요청이 여러 번 전달됨

이때 멱등성이 없다면
- 같은 요청이 여러 번 처리되어 데이터가 중복 생성되는 문제 발생함.


### HTTP 메서드와 멱등성
| HTTP Method | 멱등성       |
| ----------- | --------- |
| GET         | O         |
| PUT         | O         |
| DELETE      | O         |
| POST        | X         |
| PATCH       | X (일반적으로) |

#### GET
```
GET /users/1
```
-> 여러 번 요청해도 같은 데이터 조회

#### DELETE
```
DELETE /users/1
```
-> 여러 번 요청해도 결과는 동일 (삭제된 상태)

#### POST
```
POST /users
```
-> 여러 번 요청하면 사용자 여러 명 생성됨


### 실무 예시
결제 시스템
```
POST /payment
```
- 네트워크 오류 → 재요청 발생

👉 멱등성이 없다면 결제가 2번 될 수도 있음

그래서 실제 서비스에서는
- Idempotency Key
- 중복 요청 방지 로직

을 사용합니다.


### 면접 한 줄 정리
> 멱등성(Idempotent)은 동일한 요청을 여러 번 수행해도 결과가 변하지 않는 성질로, API 안정성과 중복 요청 처리에서 중요한 개념이다.
