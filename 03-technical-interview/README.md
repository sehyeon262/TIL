단순히 내용을 암기하는 것이 아니라, 질문을 받았을 때 핵심을 짧고 정확하게 설명하는 것을 목표로 합니다.

## Study Goal

각 개념에 대해 다음 질문에 답할 수 있도록 공부합니다.

1. 한 문장으로 정의할 수 있는가?
2. 왜 필요한지 설명할 수 있는가?
3. 비슷한 개념과의 차이를 설명할 수 있는가?
4. 실제 프로젝트에서 사용된 사례를 말할 수 있는가?
5. 기술 면접에서 30초에서 1분 안에 답변할 수 있는가?

## Note Format

각 문서는 다음 형식을 기준으로 작성합니다.

```markdown
# 주제명

## 한 문장 정의

개념을 한 문장으로 설명합니다.

## 핵심 내용

- 핵심 내용 1
- 핵심 내용 2
- 핵심 내용 3

## 비슷한 개념과의 차이

필요한 경우 표나 예시를 사용해 비교합니다.

## 기술 면접 답변

면접에서 말할 수 있는 3~5문장의 답변을 작성합니다.

## 프로젝트 연결

댕동여지도 또는 TravUs에서 사용된 위치와 역할을 작성합니다.

## 상세 학습

관련된 `01-backend` 학습 문서가 있다면 링크를 연결합니다.

## 참고자료

- 공식 문서
- 인프런 강의
- 기타 참고자료

## 출제 기업

- 실제 출제 기업 또는 공고
```
