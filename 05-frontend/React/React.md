## React
**React는 자바스크립트 기반의 UI 라이브러리로, 사용자 인터페이스를 효율적으로 구축하기 위해 설계되었음.**

- 가장 큰 특징은 컴포넌트 기반 구조로, 화면을 작은 단위로 쪼개어 **재사용성과 유지보수성을 높일 수 있음.**
- 이렇게 쪼개진 컴포넌트는 독립적으로 관리가 가능해 확장성 있는 애플리케이션 개발을 지원함.
- 데이터 흐름은 단방향으로 관리되며, 이는 상태 변화의 추적을 용이하게 하고 디버깅을 단순화함.
- JSX 문법을 사용해 자바스크립트 코드 안에서 HTML과 유사한 구조를 작성할 수 있어 UI를 보다 직관적으로 표현할 수 있음
- 방대한 커뮤니티와 생태계를 갖추고 있어 관련 라이브러리, 문서, 툴의 지원을 쉽게 받을 수 있다는 점도 React의 강점임.


-> 이러한 특징들이 결합되어 React는 대규모 프론트엔드 애플리케이션 개발에 널리 활용되는 대표적인 라이브러리임.
