# TIL

Java와 Spring 기반의 백엔드 개발자로 성장하기 위해 학습한 내용을 기록하는 저장소입니다.

강의 내용을 단순히 정리하는 데 그치지 않고, 직접 코드를 작성하고 기존 프로젝트와 연결하여 설명할 수 있는 지식으로 만드는 것을 목표로 합니다.

## Current Focus

- Java 기본 문법과 객체지향
- Spring 및 Spring Boot
- HTTP와 웹 애플리케이션 동작 원리
- 데이터베이스와 영속성
- 네트워크, 운영체제, 자료구조 등 기술 면접
- SSAFY 프로젝트 백엔드 구조 분석
- AWS 배포 및 개발 환경

## Learning Process

하나의 주제를 다음 순서로 학습합니다.

1. 강의를 통해 개념을 이해합니다.
2. 예제 코드를 직접 작성하고 실행합니다.
3. 결과를 예상한 뒤 실험으로 확인합니다.
4. 기존 프로젝트에서 관련 코드를 찾아 연결합니다.
5. 기술 면접에서 설명할 수 있도록 짧게 정리합니다.

## Note Format

각 학습 기록에는 가능한 한 다음 내용을 포함합니다.

```text
1. 핵심 개념
2. 동작 원리
3. 직접 작성한 코드
4. 실수하거나 헷갈린 부분
5. 프로젝트 적용 사례
6. 면접 예상 질문과 답변
```

## Goal

AI를 이용해 기능을 완성하는 수준을 넘어, 코드의 동작 원리와 기술 선택의 이유를 설명하고 직접 수정할 수 있는 백엔드 개발자가 되는 것이 목표입니다.
