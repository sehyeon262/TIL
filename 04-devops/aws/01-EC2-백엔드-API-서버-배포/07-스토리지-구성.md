# 💾EC2 스토리지 구성하기

EC2도 하나의 컴퓨터이므로 운영체제와 서버 파일을 저장할 공간이 필요하다. EC2에서 사용하는 저장 공간은 주로 EBS로 구성한다.

## 이 글에서 배우는 것

- EC2에 스토리지가 필요한 이유 이해하기
- EBS가 무엇인지 알아보기
- 스토리지와 볼륨의 의미 이해하기
- EC2 생성 시 스토리지 설정하기
- gp3와 용량을 선택하는 기준 알아보기

## 스토리지란?

스토리지(Storage)는 파일을 저장하는 공간이다.

노트북이나 데스크톱의 하드디스크처럼, EC2에도 운영체제와 애플리케이션 파일, 로그 파일 등을 저장할 공간이 필요하다.

EC2에서는 이 저장 공간을 스토리지 또는 볼륨(Volume)이라고 부른다.

## EBS란?

EBS(Elastic Block Store)는 EC2에 연결해서 사용하는 AWS의 블록 스토리지 서비스다.

처음에는 EC2에 연결된 하드디스크라고 생각하면 이해하기 쉽다.

```mermaid
flowchart LR
    EC2["EC2 인스턴스<br/>서버 프로그램 실행"] --- EBS["EBS 볼륨<br/>운영체제 · 서버 파일 · 로그 저장"]
```

EC2 인스턴스를 생성할 때 운영체제가 설치될 기본 EBS 볼륨도 함께 설정한다.

## 스토리지 설정

EC2 생성 화면의 스토리지 구성에서 아래와 같이 설정한다.

| 항목 | 설정 값 | 설명 |
| --- | --- | --- |
| 볼륨 유형 | `gp3` | 범용 SSD 스토리지 유형 |
| 크기 | `30 GiB` | 강의 실습에서 사용하는 저장 공간 크기 |
| 연결 대상 | EC2 인스턴스 | 생성하는 EC2에 스토리지를 연결 |

`gp3`는 범용적으로 사용하기 좋은 SSD 기반 스토리지다. 처음 EC2를 생성하는 실습에서는 `gp3`를 선택하면 된다.

## 용량은 나중에 늘릴 수 있다

처음부터 큰 용량을 설정할 필요는 없다.

서버를 운영하다가 저장 공간이 부족해지면 EBS 볼륨의 크기를 늘릴 수 있다. 따라서 실습 단계에서는 필요한 만큼만 설정하고, 사용량을 보면서 조정하면 된다.

## 비용 주의 사항

강의 실습에서는 `30 GiB`를 기준으로 설정한다.

다만 AWS 프리 티어 혜택과 무료 제공 범위는 정책에 따라 달라질 수 있다. 실습 전에 AWS 콘솔에서 현재 비용 정책과 예상 요금을 확인한다.

사용하지 않는 EC2와 연결된 EBS 볼륨은 비용이 발생할 수 있으므로, 실습을 마친 뒤 함께 정리한다.
