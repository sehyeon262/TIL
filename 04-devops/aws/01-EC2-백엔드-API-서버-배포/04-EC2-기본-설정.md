# 🎯EC2 기본 설정하기

EC2 인스턴스를 생성할 때 이름, 운영체제, 인스턴스 사양, 키 페어를 설정한다.

## 인스턴스란?

인스턴스는 AWS EC2에서 빌려 사용하는 컴퓨터 한 대를 의미한다.

인스턴스를 생성할 때는 이 컴퓨터가 어떤 용도로 사용되는지, 어떤 운영체제와 사양을 사용할지 설정해야 한다.

## 1. 이름 및 태그 설정하기

EC2 인스턴스의 이름을 정하는 단계다.

나중에 여러 인스턴스를 운영할 수 있으므로, 어떤 역할을 하는 서버인지 알아볼 수 있게 이름을 작성하는 것이 좋다.

예를 들어 백엔드 API 서버라면 다음과 같이 작성할 수 있다.

```text
instagram-server
```

## 2. 운영체제 선택하기

EC2는 사용할 운영체제를 선택할 수 있다.

이 학습에서는 Ubuntu 22.04 LTS를 사용한다.

Ubuntu는 서버 환경에서 많이 사용하는 Linux 운영체제다. Windows나 macOS보다 가볍고, 서버 실행에 필요한 환경을 구성하기 좋다.

```text
Ubuntu Server 22.04 LTS
```

## 3. 인스턴스 유형 선택하기

인스턴스 유형은 EC2 컴퓨터의 사양을 의미한다.

사양이 높을수록 더 많은 요청을 처리하고, 더 무거운 프로그램을 실행할 수 있다. 하지만 사양이 높을수록 비용도 증가할 수 있다.

이 학습에서는 프리 티어에서 사용할 수 있는 `t2.micro` 유형을 선택한다.

```text
t2.micro
```

` t2.micro `는 학습과 테스트 용도뿐 아니라, 트래픽이 많지 않은 작은 서비스에서도 사용할 수 있는 기본 사양이다.

AWS 계정과 리전에 따라 프리 티어 대상 인스턴스 유형이 다르게 보일 수 있으므로, 콘솔에서 무료 사용 가능 여부를 함께 확인한다.

## 4. 키 페어 생성하기

키 페어(Key Pair)는 EC2 인스턴스에 안전하게 접근할 때 사용하는 인증 수단이다.

비밀번호와 비슷한 역할을 하지만, 실제로는 공개 키와 개인 키로 구성된다.

키 페어 이름도 어떤 서버에 접속하기 위한 키인지 알아볼 수 있게 작성하는 것이 좋다.

```text
instagram-server-key
```

키 페어 생성 시 다음 형식을 선택한다.

```text
키 페어 유형: RSA
프라이빗 키 파일 형식: .pem
```

키 페어를 생성하면 `.pem` 파일이 다운로드된다.

이 파일은 EC2 서버에 접속할 때 필요할 수 있으므로 안전한 곳에 보관한다. 파일을 잃어버리면 다시 다운로드할 수 없으며, GitHub에 올리면 안 된다.

## 정리

- 인스턴스는 AWS에서 빌리는 컴퓨터 한 대다.
- 인스턴스 이름은 서버 역할을 알 수 있게 작성한다.
- 이 학습에서는 Ubuntu 22.04 LTS를 사용한다.
- 인스턴스 유형은 컴퓨터 사양을 의미한다.
- 키 페어의 `.pem` 파일은 외부에 노출하지 않고 안전하게 보관한다.
