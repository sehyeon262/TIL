# 🎯리전(Region) 선택하기

EC2 인스턴스를 생성하기 전에 서비스를 운영할 AWS 리전을 선택한다.

## 리전이란?

리전(Region)은 AWS 인프라가 위치한 지리적 영역이다.

AWS는 전 세계 여러 지역에 데이터 센터를 운영하고 있다. EC2를 통해 빌리는 컴퓨터도 각 리전에 나뉘어 있다.

리전은 고유한 이름을 가진다.

- `ap-northeast-2`: 아시아 태평양(서울)
- `us-east-1`: 미국 동부(버지니아 북부)
- `eu-west-3`: 유럽(파리)

## 리전은 어떤 기준으로 선택할까?

### 1) 주 사용자의 위치

사용자와 서버가 멀리 떨어져 있을수록 네트워크 요청이 오가는 시간이 길어진다.

따라서 서비스의 주 사용자가 있는 위치와 가까운 리전을 선택하는 것이 좋다.

예를 들어 한국 사용자가 주로 사용하는 서비스라면 아시아 태평양(서울) 리전을 선택할 수 있다.

### 2) 서비스 리소스의 위치

EC2, RDS, ELB 같은 AWS 리소스는 리전별로 관리된다.

서로 연결해서 사용할 리소스는 같은 리전에 생성하는 것이 일반적이다.

## EC2 리전 선택하기

AWS 콘솔에서 EC2 서비스로 이동한 뒤, 화면 상단에서 사용할 리전을 선택한다.

이 학습에서는 아시아 태평양(서울) 리전을 기준으로 진행한다.

```text
Asia Pacific (Seoul)
ap-northeast-2
```

## 주의 사항

리전마다 EC2 인스턴스와 AWS 리소스가 따로 관리된다.

예를 들어 서울 리전에 EC2 인스턴스를 생성한 뒤, 미국 동부 리전으로 이동하면 생성한 인스턴스가 보이지 않는다.

인스턴스가 삭제된 것이 아니라 다른 리전을 보고 있는 경우일 수 있으므로, 먼저 현재 선택된 리전을 확인한다.

## 정리

- 리전은 AWS 인프라가 위치한 지리적 영역이다.
- 사용자의 위치와 가까운 리전을 선택하면 응답 속도에 유리하다.
- AWS 리소스는 리전별로 따로 관리된다.
- 한국 사용자를 대상으로 하는 서비스라면 서울 리전을 선택할 수 있다.
