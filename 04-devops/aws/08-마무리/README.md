# 💸AWS 비용 발생 여부 확인하기

AWS 실습이 끝난 뒤 어떤 서비스에서 비용이 발생했는지 확인하고, 사용하지 않는 리소스를 정리하는 방법을 기록한다.

## 이 섹션에서 확인할 것

- 이번 달 AWS 사용 요금 확인하기
- 비용이 발생한 AWS 서비스 확인하기
- 사용하지 않는 리소스 정리하기
- 리소스를 삭제한 뒤 비용 발생 여부 다시 확인하기

## 먼저 알아야 할 핵심 개념

### 1) 리소스를 만들면 비용이 발생할 수 있다

AWS는 사용한 서비스와 사용량에 따라 비용이 발생한다.

무료 티어를 사용하더라도 사용량을 초과하거나 무료 대상이 아닌 리소스를 생성하면 비용이 발생할 수 있다.

### 2) 비용은 서비스별로 확인할 수 있다

AWS Billing and Cost Management에서 현재까지 발생한 비용과 비용이 발생한 서비스를 확인할 수 있다.

예상보다 비용이 발생했다면 먼저 어떤 서비스에서 청구되었는지 확인한 뒤, 해당 리소스가 아직 남아 있는지 점검한다.

### 3) 종료와 삭제는 다를 수 있다

일부 리소스는 인스턴스를 중지해도 연결된 저장 공간, 스냅샷, 공인 IP 같은 항목에서 비용이 발생할 수 있다.

따라서 실습이 끝난 뒤에는 서비스별 정리 문서를 확인하고, 실제로 리소스가 삭제되었는지 다시 점검해야 한다.

## 비용 확인 순서

1. AWS Billing and Cost Management에 접속한다.
2. 현재 청구 기간의 비용을 확인한다.
3. 비용이 발생한 AWS 서비스를 확인한다.
4. 사용하지 않는 리소스가 남아 있는지 확인한다.
5. 각 서비스의 정리 문서를 참고해 리소스를 삭제한다.
6. 이후 다시 비용 화면을 확인한다.

## 확인해야 할 주요 리소스

- EC2 인스턴스와 연결된 EBS 볼륨
- 사용하지 않는 Elastic IP
- ELB
- RDS 인스턴스와 스냅샷
- Route 53 호스팅 영역과 도메인
- S3 버킷에 저장된 파일
- CloudFront 배포

## 마무리 체크리스트

- [ ] EC2 인스턴스를 종료하거나 삭제했다.
- [ ] 사용하지 않는 Elastic IP를 해제했다.
- [ ] ELB를 삭제했다.
- [ ] RDS 인스턴스와 불필요한 스냅샷을 정리했다.
- [ ] 사용하지 않는 S3 버킷과 객체를 정리했다.
- [ ] CloudFront 배포를 삭제했다.
- [ ] AWS 비용 화면에서 예상하지 못한 청구가 없는지 확인했다.

## 주의 사항

- AWS 비용 정보는 즉시 반영되지 않을 수 있으므로, 리소스를 정리한 뒤에도 다시 확인한다.
- 도메인은 구매 기간에 따라 비용이 발생할 수 있으므로 자동 갱신 설정을 확인한다.
- 삭제 전에 필요한 데이터와 백업이 있는지 먼저 확인한다.
