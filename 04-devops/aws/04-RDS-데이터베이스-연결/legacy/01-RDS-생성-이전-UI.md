# 🕰️RDS 생성하기: 이전 AWS UI

> 이 문서는 이전 AWS 콘솔 화면을 사용하던 시기의 참고용 기록이다.  
> 실제 실습은 최신 화면 기준 문서인 [RDS 데이터베이스 생성하기](../03-RDS-생성.md)를 따른다.

AWS 콘솔 UI는 시간이 지나면서 메뉴 이름과 화면 구성이 달라질 수 있다.

이전 UI에서도 RDS 생성 과정의 핵심은 동일하다.

- EC2와 같은 리전 선택
- MySQL 엔진 선택
- 학습용 템플릿 선택
- DB 인스턴스 식별자와 마스터 계정 설정
- 연결 및 퍼블릭 액세스 설정
- 비용 확인 후 생성

## 현재 문서와의 차이

| 구분 | 이전 UI | 현재 UI |
| --- | --- | --- |
| 화면 구성 | 생성 옵션의 위치와 이름이 다를 수 있음 | 현재 AWS 콘솔 기준으로 정리 |
| 템플릿 이름 | 프리 티어 관련 표현이 다를 수 있음 | 계정과 리전의 현재 표시 기준 확인 필요 |
| 네트워크 설정 | 연결 옵션의 배치가 다를 수 있음 | 현재 VPC·보안 그룹 화면 기준 |
| 권장 문서 | 참고용 | 실제 실습용 |

## 핵심 주의 사항

UI가 달라도 마스터 암호를 GitHub에 올리지 않고, RDS 보안 그룹에서 MySQL 포트 `3306`의 접근 대상을 제한해야 한다는 원칙은 변하지 않는다.
