# 🌐Route 53으로 도메인 연결하기

EC2에 배포한 백엔드 서버에 사람이 읽기 쉬운 도메인 주소를 연결하는 과정을 정리한다.

## 이 섹션에서 배우는 것

- 도메인과 DNS의 역할 이해하기
- Route 53에서 도메인 구매하기
- 도메인을 EC2 서버에 연결하기
- 무료 도메인을 사용하는 방법 알아보기
- Route 53 사용 후 비용이 발생하지 않도록 정리하기

## 먼저 알아야 할 핵심 개념

### 1) 도메인이란?

도메인은 IP 주소를 사람이 기억하기 쉬운 문자 형태로 표현한 인터넷 주소다.

예를 들어 `www.naver.com`이나 `youtube.com`이 도메인이다.

서버는 IP 주소를 통해 통신할 수 있지만, 숫자로 이루어진 IP 주소는 외우기 어렵고 서버 주소가 변경될 수도 있다. 도메인을 사용하면 사용자는 기억하기 쉬운 주소로 서비스에 접속할 수 있다.

### 2) DNS란?

DNS(Domain Name System)는 도메인 주소를 실제 IP 주소로 변환해 주는 시스템이다.

사용자가 도메인 주소로 접속하면 DNS가 연결된 서버의 IP 주소를 찾아 준다.

### 3) Route 53이란?

Route 53은 AWS에서 도메인을 구매하고 DNS 설정을 관리할 수 있는 서비스다.

Route 53을 사용하면 도메인과 EC2 서버를 연결할 수 있다. 이후 사용자는 IP 주소 대신 도메인 주소로 서버에 접근할 수 있다.

### 4) 도메인과 HTTPS

실제 서비스는 보통 IP 주소보다 도메인 주소를 사용한다.

도메인이 있으면 ELB와 ACM을 활용해 HTTPS를 적용할 수 있다. 다음 섹션에서는 도메인과 ELB를 연결하고 HTTPS를 설정한다.

## 주의 사항

- 도메인 구매와 Route 53 호스팅 영역은 비용이 발생할 수 있다.

- DNS 레코드를 변경할 때는 연결 대상 IP 주소와 레코드 타입을 다시 확인한다.
