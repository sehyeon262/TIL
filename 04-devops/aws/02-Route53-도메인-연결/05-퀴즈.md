# 🧩Route 53 퀴즈

Route 53, 도메인, DNS, A 레코드 내용을 이해했는지 확인하는 퀴즈다.

정답을 보기 전에 먼저 직접 답을 생각해 본다.

## 1. 도메인의 역할

도메인을 사용하는 가장 중요한 이유는 무엇일까?

1. EC2 인스턴스의 CPU 성능을 높이기 위해
2. IP 주소를 사람이 기억하기 쉬운 주소로 사용하기 위해
3. 서버의 포트를 자동으로 열기 위해
4. 데이터베이스를 생성하기 위해

<details>
<summary>정답 보기</summary>

정답은 **2번**이다.

도메인은 IP 주소를 사람이 기억하기 쉬운 문자 형태의 주소로 표현한 것이다.

</details>

## 2. DNS의 역할

사용자가 `example.com`으로 접속했을 때 DNS가 하는 일은 무엇일까?

1. 도메인에 연결된 IP 주소를 찾아 준다.
2. EC2 인스턴스를 새로 생성한다.
3. HTTPS 인증서를 자동으로 발급한다.
4. 서버의 소스 코드를 배포한다.

<details>
<summary>정답 보기</summary>

정답은 **1번**이다.

DNS는 도메인 이름을 실제 IP 주소로 변환해 준다.

</details>

## 3. A 레코드

도메인을 EC2의 탄력적 IP 주소에 연결하려고 한다. 어떤 레코드 유형을 사용해야 할까?

1. A 레코드
2. CNAME 레코드
3. MX 레코드
4. TXT 레코드

<details>
<summary>정답 보기</summary>

정답은 **1번**이다.

A 레코드는 도메인을 IPv4 주소에 연결할 때 사용한다.

</details>

## 4. CNAME 레코드

CNAME 레코드는 언제 사용할까?

1. 도메인을 IPv4 주소에 연결할 때
2. 도메인을 다른 도메인 주소에 연결할 때
3. 서버 포트를 열 때
4. EC2에 탄력적 IP를 연결할 때

<details>
<summary>정답 보기</summary>

정답은 **2번**이다.

예를 들어 `www.example.com`을 `example.com`으로 연결할 때 CNAME 레코드를 사용할 수 있다.

</details>

## 5. 루트 도메인 연결

`example.com` 자체를 EC2의 탄력적 IP에 연결하려고 한다.

A 레코드를 생성할 때 레코드 이름은 어떻게 설정할까?

1. `example`
2. `www`
3. `api`
4. 비워 둠

<details>
<summary>정답 보기</summary>

정답은 **4번**이다.

레코드 이름을 비워 두면 루트 도메인인 `example.com`에 연결된다.

</details>

## 6. 서브도메인 연결

`api.example.com`을 EC2 서버에 연결하려고 한다.

레코드 이름에는 무엇을 입력해야 할까?

<details>
<summary>정답 보기</summary>

정답은 `api`다.

Route 53은 기본 도메인인 `example.com` 뒤에 레코드 이름을 붙여 `api.example.com`을 만든다.

</details>

## 7. 탄력적 IP를 사용하는 이유

EC2의 일반 퍼블릭 IPv4 주소 대신 탄력적 IP를 사용하는 이유는 무엇일까?

<details>
<summary>정답 보기</summary>

EC2 인스턴스를 중지했다가 시작하면 일반 퍼블릭 IPv4 주소는 변경될 수 있다.

탄력적 IP는 연결을 유지하는 동안 고정된 IP 주소를 사용할 수 있으므로 도메인 연결에 적합하다.

</details>

## 8. 도메인과 포트

A 레코드에 EC2의 탄력적 IP를 등록했다.

서버가 `3000` 포트에서 실행 중이라면 아래 중 올바른 접속 주소는 무엇일까?

1. `http://example.com`
2. `http://example.com:3000`
3. `http://3000.example.com`
4. `http://example.com/ip`

<details>
<summary>정답 보기</summary>

정답은 **2번**이다.

A 레코드는 도메인과 IP 주소만 연결한다. 포트는 연결하지 않으므로 서버가 `3000` 포트에서 실행 중이면 URL에 포트 번호를 입력해야 한다.

</details>

## 9. 도메인 연결이 바로 되지 않을 때

A 레코드를 생성했는데 도메인 접속이 되지 않는다. 가장 먼저 확인할 항목으로 적절하지 않은 것은 무엇일까?

1. A 레코드 값이 탄력적 IP와 일치하는지 확인한다.
2. EC2 인스턴스가 실행 중인지 확인한다.
3. 보안 그룹에서 서버 포트를 허용했는지 확인한다.
4. RDS 데이터베이스가 생성되었는지 확인한다.

<details>
<summary>정답 보기</summary>

정답은 **4번**이다.

도메인으로 EC2 서버에 접속하는 문제와 RDS 생성 여부는 직접적인 관계가 없다.

</details>

## 10. 무료 도메인 사용

무료 도메인 사용이 적절한 상황은 무엇일까?

1. 결제 서비스가 있는 운영 서버
2. 사용자 수가 많은 실제 서비스
3. DNS와 서버 연결을 연습하는 개인 프로젝트
4. 중단되면 안 되는 회사 서비스

<details>
<summary>정답 보기</summary>

정답은 **3번**이다.

무료 도메인은 학습과 테스트에 유용하지만, 실제 운영 서비스에는 안정적인 유료 도메인을 사용하는 것이 좋다.

</details>
